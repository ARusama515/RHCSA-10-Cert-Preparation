# RHCSA-10-Cert-Preparation
RHCSA (EX200) certification

### My RHCSA EX200 (RHEL 10) Preparation Plan

Hi, My name is Abdul Rub Usama I am a DevOps Engineer with 1 year of Experience. This is my personal preparation plan for the RHCSA EX200 certification. I am preparing for this exam through my own research and practical hands-on practice.

The RHCSA EX200 exam is now based on **RHEL 10** (current version in 2026). It is a performance-based exam, so the entire focus is on practical and hands-on skills.

### Complete 20-Stage Preparation Plan

I have divided my preparation into **exactly 20 stages**. Each stage is well structured and includes:

- Theory & Concepts  
- Key Commands & Configurations (RHEL 10 specific)  
- Hands-on Labs (using Vagrant to create 2–3 virtual machines for real practice)  
- Self-Assessment / Quiz  
- Common Exam Pitfalls and Troubleshooting Tips  

**Vagrant Lab Setup**: In every stage, I will practice on real virtual machines (Rocky Linux 10 or RHEL 10) to create an exam-like environment.

### Detailed 20-Stage Plan

**Stage 1**: Introduction to RHCSA & RHEL 10 + Vagrant Lab Environment Setup  
**Stage 2**: Essential Tools – Part 1 (File & Directory management: ls, cp, mv, rm, find, locate)  
**Stage 3**: Essential Tools – Part 2 (Redirection, Pipes, grep, regex, cut, tr, wc, sort, uniq)  
**Stage 4**: Essential Tools – Part 3 (vi/vim editor mastery, man/info/help, compression with tar/gzip/xz)  
**Stage 5**: Software Management (dnf, rpm, repositories, modules, Flatpak)  
**Stage 6**: Create Simple Shell Scripts – Part 1 (basics, variables, shebang, permissions, I/O)  
**Stage 7**: Create Simple Shell Scripts – Part 2 (conditionals, loops, functions, positional parameters)  
**Stage 8**: Operate Running Systems – Part 1 (Processes, jobs, signals, ps, top, kill, nice/renice)  
**Stage 9**: Operate Running Systems – Part 2 (systemd services, systemctl, unit files)  
**Stage 10**: Operate Running Systems – Part 3 (Boot process, GRUB, targets, emergency/rescue mode, kernel parameters)  
**Stage 11**: Configure Local Storage – Part 1 (Partitions with parted/fdisk, swap, UUID, persistent mounting)  
**Stage 12**: Configure Local Storage – Part 2 (LVM – pvcreate, vgcreate, lvcreate, extend, reduce, snapshots)  
**Stage 13**: Create & Configure File Systems – Part 1 (XFS/ext4, mkfs, mount, fstab, Stratis basics)  
**Stage 14**: Create & Configure File Systems – Part 2 (Permissions, umask, special permissions, ACLs)  
**Stage 15**: Manage Users & Groups (useradd, groupadd, sudo, password policies, id, getent)  
**Stage 16**: Manage Basic Networking (nmcli, ip commands, hostname, static/dynamic IP, DNS)  
**Stage 17**: Manage Security – Part 1 (firewalld, firewall-cmd, zones, rich rules)  
**Stage 18**: Manage Security – Part 2 (SELinux – enforcing/permissive, contexts, restorecon, semanage, booleans)  
**Stage 19**: Deploy, Configure & Maintain Systems (journalctl, cron, systemd timers, tuned profiles, performance monitoring)  
**Stage 20**: Full System Review + Mock Exams + Exam Strategies + Final Troubleshooting Labs  

These 20 stages cover the complete RHCSA syllabus along with extra practical exercises so that I feel fully confident in the exam hall.
